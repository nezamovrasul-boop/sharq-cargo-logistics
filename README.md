# SHARQ Cargo Logistics

Сайт логистической компании: доставка из Китая в Узбекистан.

**[Открыть сайт для просмотра](https://nezamovrasul-boop.github.io/sharq-cargo-logistics/)**

- Русская и узбекская версии, адаптация для телефона и компьютера.
- Автомобильные, авиационные и железнодорожные перевозки.
- Крупногабаритные, огнеопасные и другие типы грузов.
- Интерактивная карта с Гуанчжоу, Иу, Пекином, Шэньчжэнем и Хоргосом.
- Пошаговая заявка с подготовкой сообщения в WhatsApp. Автоматической отправки нет.
- Оригинальный логотип и сгенерированные фотографии.

Карта показывает географию, а не отслеживание груза. Маршруты, сроки, стоимость и документы согласуются с менеджером.

## Локальный просмотр

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Сборка и установка зависимостей не требуются.

## Структура

`index.html` — страница; `app.js` — переводы; `experience.js` — карта и заявка; `editorial.js` — оформление заголовков; `assets/` — изображения, логотипы и географические данные; `vendor/` — MapLibre GL JS.

Сайт опубликован через GitHub Pages из корня ветки `main`.
